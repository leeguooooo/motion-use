# motion-use 推广片 · 102 秒

**看完记住什么**：motion-use 让 coding agent 当导演。画面写成时间的函数，渲染全在本地，交付前会实测成片，但最后要有人看过才算通过。

**画面主线**：一条发光的时间线贯穿全片。开场那句需求落到地上，熔成这条线；分镜卡沿着它立起，播放头在上面拖动，帧从它上面升起，旁白块装进它的镜头窗口，成片沿它穿过扫描环。毛线接力片里的红色毛毡小怪物当向导，陪观众走完这条线。

**技术**：three.js 场景（`src/scene.js` + 共享的毛毡模块 `src/felt.js`）打包成 `vendor/scene.js`，通过 `libraries` 加载；`composition/draw.js` 只负责字幕和淡入淡出。屏幕上的字全部来自 `film.copy`，保证进入字体子集。旁白用 edge-tts（预览用途），配乐和音效由 `audio/score.py` 合成。

## 核实过的事实（来源）
- 逐帧定位、多进程分段截帧：`references/film.md`（"The renderer seeks backward and splits capture among workers"）。
- 渲染不联网、引擎统计关闭：`src/hf.mjs` 的 `HF_ENV`，`src/brief.mjs` 的网络规则。
- 字体按用到的字裁剪：`src/build.mjs` → `writeSubsets`；film 的字来自 copy 和绘制源码。
- 旁白缺失、超长或未混入都会失败：`src/verify.mjs` 的人声相关性检查，`references/film.md`。
- 响度目标 -14 LUFS / -1 dBTP，黑场和静止区间：`src/verify.mjs`。
- `visual_review` 默认 pending：render 的报告字段。

## 评审记录
- 第 1 轮静帧：取景普遍太远、字太小；分镜卡被 Bloom 吹白；时间段的镜头没跟住播放头；帧太小。已重新取景、放大，卡片压暗避开 Bloom，并加了发光轨迹表达“姿态 = f(t)”。
- 第 2 轮：胶片右半边被半透明底板盖住（排序问题），已固定绘制顺序；代码面板文字被截断；开场英文字距不均，改为按真实字宽排版。
- 加了烧录字幕：README 里的视频默认静音播放。
- 草稿：0 故障帧，9 段旁白相关性 0.94–0.99；7.0–7.8 秒有静止。原因是相机在关键帧处减速到零，已改为连续插值；开场加了光脉冲和向导入场。

## 尚存问题
- 只有中文旁白；英文版需要另配旁白、调整时间。
- edge-tts 是预览用途，正式公开发布前最好换成有授权的语音。
- 配乐只做了频谱和响度测量，没有人耳试听。
